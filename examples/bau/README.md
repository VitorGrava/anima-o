# Baú abrindo (32x32, 10 frames)
Referência estudada (só local, não redistribuída): Wooden Treasure Chests, szymon18042 (itch.io).
Características seguidas: vista frontal larga com orelhas e cinta douradas; contorno único roxo-escuro; madeira em 3 tons com tracinhos de tábua; cadeado de aço (topo claro, base escura); aberto = tampa sobe com a face vermelha, interior azul-marinho e aro dourado.
Gerado por `gen.mjs` (rode: node gen.mjs; node bin/anima.mjs new ...; run ... cmds.json).
